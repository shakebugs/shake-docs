# Claude Code
> Here’s how to connect Claude Code to your Shake workspace.

:::note
Firstly, you need to
have [Claude Code extension](https://marketplace.visualstudio.com/items?itemName=anthropic.claude-code) for Visual Studio
Code installed.
:::

To add Shakebugs MCP to your project, simply run the following command in the terminal:

```bash title="Terminal"
// highlight-next-line
claude mcp add Shake https://mcp.shakebugs.com/mcp -t http -s user
```

That’s it! You can now ask Claude questions about your Shake tickets — [see examples](/docs/mcp/overview.md#prompt-examples).
